Discrete Probability Distributions in Machine Learning

Stochastic modeling of discrete random events provides foundational backing for classification uncertainty, Bernoulli Naïve Bayes, token likelihood estimation, queuing systems, and rare event anomaly detection.

Active Module Module 01

Binomial Distribution

X ~ B(n, p)

Evaluates success counts across $n$ independent Bernoulli trials with parameter $p$.

Active Module Module 02

Poisson Distribution

X ~ Poisson(λ)

Models frequency of occurrences across a continuous interval or fixed temporal/spatial window given rate $\lambda$.

Upcoming Module 03

Geometric Distribution

X ~ Geo(p)

Discrete trials needed to achieve the first successful event with memoryless behavior.

Geometric Distribution

Module 03 • Upcoming

Models number of Bernoulli trials needed to achieve the first successful event.

X ~ Geo(p)

PMF: P(X = k) = (1 - p)k - 1 · p,   for k = 1, 2, 3, ...

Moments: Mean = 1/p,   Variance = (1 - p)/p²

Key Property: Memorylessness — P(X > s + t | X > s) = P(X > t)
